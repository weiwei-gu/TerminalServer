Linux 常用命令指南

rm file删除文件
rm -r dir删除目录

mv src dst移动/重命名文件
touch file创建空文件
cat file查看文件内容
head -n file查看文件前 n 行
tail -n file查看文件后 n 行

find . -name "*.txt"查找 txt 文件

chown user file修改所有者

free -h查看内存使用

ps aux查看所有进程

curl url请求 URL
wget url下载文件
netstat -tuln查看端口
